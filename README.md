# 네이버 뉴스 자동 수집 및 Slack 발송 시스템

> 배달·소상공인·외식업 관련 이해관계자 동향을 매일 오전 10시에 자동 수집·필터링하여 Slack에 발송하는 자동화 시스템

---

## 구성 파일 개요

```
news_collector/
  naver_news_collect.py   ← 뉴스 수집 엔진
  criteria.md             ← 키워드별 필터링 기준
  results/                ← 수집 결과 저장소
```

+ Claude Code Routines: `daily-naver-news` ← 전체 프로세스 자동 실행

---

## 1. naver_news_collect.py

### 역할
네이버 뉴스를 실제로 수집하는 엔진. 키워드로 검색해서 기사 제목·링크·본문을 가져오고 `results/` 폴더에 저장합니다.

### 변경 가능한 항목과 결과

| 변경 항목 | 위치 | 변경하면? |
|---|---|---|
| 키워드 추가/삭제 | 상단 `KEYWORDS = [...]` | 수집 대상 기관/주제가 늘거나 줄어듦 |
| 규제 그룹 검색어 | `{"folder": "규제", "keywords": [...]}` | 규제 폴더에 담기는 검색어 변경 |
| 수집 페이지 수 | `MAX_PAGES = 3` | 숫자 높이면 더 많은 기사 수집 (속도 느려짐) |
| 중복 판단 기준 | `SIMILARITY_THRESHOLD = 0.30` | 높이면 더 많이 제거, 낮추면 유사 기사도 남김 |
| 검색 기간 | URL의 `pd=4` (1일) | `pd=2`로 바꾸면 1주일치 수집 |

### 현재 수집 키워드 (11개)

| 유형 | 키워드 |
|---|---|
| 정부기관 | 중소벤처기업부, 동반성장위원회 |
| 소상공인 단체 | 소상공인연합회, 전국상인연합회, 전국카페사장협동조합, 전국가맹점주협의회 |
| 외식·프랜차이즈 | 한국외식업중앙회, 한국프랜차이즈산업협회 |
| 플랫폼 | 배달의민족, 배달 사회적대화기구 |
| 규제 (그룹) | 배달앱 수수료 + 온플법 + 공정위 배달앱 + 플랫폼 공정위 → `규제` 폴더로 통합 |

### 결과물
```
news_collector/results/
  중소벤처기업부/20260607_100012.txt
  소상공인연합회/20260607_100034.txt
  규제/20260607_100112.txt
  ...
```

## 2. criteria.md

### 역할
수집된 기사를 Claude가 필터링할 때 판단 기준이 되는 문서입니다.
키워드별로 "이런 기사는 포함, 저런 기사는 제외"를 정의합니다.

### 변경 가능한 항목과 결과

| 변경 항목 | 변경하면? |
|---|---|
| 포함 기준 추가 | 해당 유형 기사가 더 많이 채택됨 |
| 제외 기준 추가 | 해당 유형 기사가 탈락됨 |
| 특정 인물명 추가 | 그 인물 관련 기사가 포함/제외됨 |
| 키워드 섹션 추가 | 새 키워드에 대한 필터링 기준 생성 |

### 변경 예시
```markdown
## 소상공인연합회

### 포함
- 공식 성명·기자회견
- 송치영 회장 발언         ← 기존
- 홍길동 신임 회장 발언    ← 추가하면 이 인물 관련 기사도 채택됨

### 제외
- 지역 한정 행사           ← 추가하면 해당 기사 탈락
```

### 결과물
criteria.md 자체는 파일 저장 결과 없음.
Routine 실행 시 Claude가 읽어서 **Slack 메시지에 포함되는 기사 수와 내용**이 달라집니다.

## 3. daily-naver-news (Routine)

### 역할
전체 프로세스를 자동으로 실행하는 지휘자입니다.
평일 오전 10시에 Python 실행 → 필터링 → Slack 발송까지 순서대로 지시합니다.

### 실행 프로세스
```
평일 오전 10시
      ↓
① 뉴스 수집
   python news_collector/naver_news_collect.py 실행
   → 11개 키워드별 네이버 최근 24시간 기사 수집
   → 제목 유사도 기반 1차 중복 제거
   → results/ 폴더에 키워드별 txt 저장
      ↓
② 필터링
   criteria.md 기준 적용
   → 키워드별 포함/제외 기준으로 관련 없는 기사 탈락
   → 본문 70% 이상 동일한 기사 추가 제거
      ↓
③ 메시지 구성
   정해진 형식으로 Slack 메시지 작성
      ↓
④ Slack 발송
   #ai-코칭-앤-피코칭 채널에 전송
```

### 변경 가능한 항목과 결과

| 변경 항목 | 변경하면? |
|---|---|
| 실행 시간 `0 10 * * 1-5` | 숫자 바꾸면 발송 시간 변경 (예: `0 9 * * 1-5` → 오전 9시) |
| Slack 채널 ID | 다른 채널로 발송됨 |
| 파일 경로 | 다른 PC에 설치할 때 본인 경로로 수정 |
| 키워드 표시 순서 | Slack 메시지에서 섹션 나오는 순서 변경 |
| 메시지 형식 | 헤더 문구, 들여쓰기 등 Slack 메시지 디자인 변경 |

### Routine 수정 방법
> Claude Code → Routines → `daily-naver-news` → 편집

### 결과물
```
오늘의 주요 이해관계자 관련 뉴-우스 (6/9, 월)

• 중기부:
   ○ 기사 제목 (링크)
   ○ 기사 제목 (링크)

• 소상공인연합회: 기사 제목 (링크)

• 배달의민족:
   ○ 기사 제목 (링크)
...
```

## 세 파일의 관계

```
naver_news_collect.py  →  results/*.txt  →  criteria.md  →  Slack 메시지
       (수집)               (원본 데이터)     (필터링 기준)    (최종 결과물)
          ↑                                       ↑
    키워드 수정으로                           기준 수정으로
    수집 범위 변경                            채택 기사 변경
```

| 목적 | 수정 파일 |
|---|---|
| 수집 키워드·범위 변경 | `naver_news_collect.py` |
| 필터링 기준 변경 | `criteria.md` |
| 발송 시간·채널·형식 변경 | `daily-naver-news` Routine |

## 팀원 설치 가이드

### 전달 파일
- `naver_news_collect.py`
- `criteria.md`

### 설치 순서

**1. 폴더 생성**
```
C:\Users\<본인PC이름>\AI\news_collector\
  naver_news_collect.py
  criteria.md
  results\          ← 빈 폴더 직접 생성
```

**2. Python 라이브러리 설치**
```bash
pip install requests beautifulsoup4 lxml trafilatura urllib3
```

**3. Claude Code 앱 설치**
- [claude.ai/download](https://claude.ai/download) 에서 설치 후 로그인

**4. Slack 연결**
- Claude Code → Customize → Slack MCP 연결

**5. Routine 등록**
Claude Code에서 아래 메시지 입력:
```
daily-naver-news Routine 만들어줘.
내 PC 경로는 C:\Users\<본인PC이름>\AI\ 이야.
평일 오전 10시에 뉴스 수집 후 Slack C0B3CE5B0GM 채널에 발송해줘.
```

**6. 첫 실행 테스트**
- Routines → `daily-naver-news` → **Run now** 클릭
- Slack 채널에 메시지 오면 설치 완료 ✅

### 주의사항
- Claude Code 앱이 **열려 있을 때만** Routine 실행됨
- PC가 평일 오전 10시에 켜져 있어야 함
- Python 3.12 권장
